## Negative cases and oracle

`tests/contract/test_model.c` contains 252 world/persistence/class transitions,
49 device transitions, an independent caller-role table, failure-preservation
checks, malformed state/enum/range cases for every command, and 2000 malformed
requests from fixed seed 0x4a414e55. No failing seeded input occurred. This is
bounded stress, not coverage-guided fuzzing or exhaustive verification.

Scenario functions test revocation before admission, draining admitted work,
descendant revocation, attenuation, stale grants/events after restore, unknown
external completion, object conflict/IO failure, budget/slot/counter exhaustion,
viewer loss, owner recovery, retained leases on stop/failed restore, and failed
reset quarantine. Every rejected operation in `expect()` compares the entire
state against its prior bytes. Tables derive from candidate contracts, not model
helpers. Same-agent authorship remains a shared-assumption risk; see
[boundary review](m0-boundary-review.md).

## Limits and next action

PASS means model semantics/checks only. No OS capability enforcement, production
authentication, network isolation, crash-safe disk I/O, cryptographic anti-rollback,
actual thread races, guest boot, DMA isolation or physical reset tested.
Allocation failure is NOT APPLICABLE: model has no dynamic allocations; fixed
slot exhaustion is tested. Lifetime slots are intentionally never recycled.
Recovery resource reservation is conceptual, not a scheduler guarantee.

Drain can stay BUSY for an uncooperative world; backend cancellation and real
reconciliation need a later contract. Actor labels and object/grant indices are
not unforgeable authority. Unknown results cannot be retried automatically and
external effects do not rewind. No licence/native substrate/stable ABI/storage
format/hardware/key policy selected. ADR 0001 is EXPERIMENTAL, not accepted.

Next permitted action: maintainer review of M0. [M1 candidate plan](../plans/m1-candidate.md)
is NOT AUTHORISED for implementation. No M1/kiosk/hardware work started.
