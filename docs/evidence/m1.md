## Implementation and oracle

C17 janusd/janusctl use owner-local authenticated SOCK_SEQPACKET, fixed commands,
trusted URI/UUID profiles, independent backend and viewer adapters, explicit
incarnation records and bounded owned-child recovery. See
[runbook/contract](../development/HOSTED_M1.md), [ADR 0003](../decisions/0003-m1-hosted.md),
[boundary review](m1-boundary-review.md) and [dependency/fixture provenance](m1-dependencies.md).

Expected state tables were authored separately from the state implementation,
using the maintainer's scenarios as oracle. Fake adapters inject backend/start/
spawn/save/stop failures; they do not count as live libvirt evidence. Process
tests exercise real fork/exec/wait/signal and rlimit failures. Live checks compare
JANUS output with independent libvirt UUID/state, QEMU's display-client query,
serial PID1 boot/reboot/poweroff markers and verified process parentage.
One agent authored and reviewed this work; no independent-human acceptance claim.
